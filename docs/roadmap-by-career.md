# Master roadmap: 0 to professional in technology

This master roadmap is the full learning architecture behind this repository. It is designed to be broad enough to cover all relevant domains without losing clarity or sequence.

## Core principle

Do not learn everything at once. Learn in layers:

1. Foundations
2. Programming and problem solving
3. Linux, systems, and tooling
4. Software engineering and systems design
5. Specialization in one domain
6. Production engineering and real-world delivery
7. Portfolio, open source, and professional maturity

## Phase 1: Foundations (0-3 months)

### Goals
- Understand computation, logic, and math
- Learn at least one language deeply
- Learn terminal workflow and Git
- Build a disciplined study routine

### Topic map
- Algebra, logic, arithmetic, binary, hexadecimal
- Probability and basic statistics
- Discrete math fundamentals
- Variables, conditionals, loops, functions, recursion
- Debugging and reading errors
- CLI usage and file system navigation
- Git and GitHub basics
- Shell scripting basics
- Intro to networks and operating systems

### Deliverables
- Solve beginner algorithm problems
- Write 3 small programs
- Use Git daily
- Learn Linux navigation and file manipulation
- Build a basic CLI project

## Phase 2: Programming and algorithmic thinking (3-6 months)

### Goals
- Become comfortable writing real programs
- Understand data structures and algorithmic thinking
- Improve debugging and analytical habits

### Topic map
- Arrays, lists, tuples, sets, dicts
- Stacks, queues, hash maps, trees, graphs
- Sorting and search
- Recursion and memoization
- Dynamic programming basics
- Greedy algorithms
- Complexity analysis: O(n), O(log n), O(n log n)
- OOP basics and clean code
- Testing basics
- Error handling and resilience

### Deliverables
- 30-50 coding exercises
- 2 medium-sized programs
- Basic understanding of complexity and trade-offs
- Use version control and issue tracking

## Phase 3: Linux, OS, and systems fundamentals (3-8 months)

### Goals
- Understand how computers and operating systems work
- Use Linux like a power user
- Learn how process and memory work

### Topic map
- Linux filesystem hierarchy
- Processes and threads
- Signals and IPC
- Shell scripting
- Permissions and ownership
- Package management
- System calls and user/kernel space
- Memory and runtime behavior
- Logs and troubleshooting
- Networking basics
- Virtualization and containers

### Deliverables
- Build shell utilities or automation tools
- Write scripts for file processing and system tasks
- Understand process monitoring and logs
- Run Docker locally

## Phase 4: Core software engineering (4-10 months)

### Goals
- Learn how software is designed and maintained
- Learn databases, APIs, and application architecture
- Understand production engineering basics

### Topic map
- SQL and relational design
- ER diagrams and schema basics
- HTTP, REST, JSON, API design
- Backend fundamentals
- Frontend fundamentals
- Testing: unit, integration, end-to-end
- Design patterns
- Git workflows and code review
- Networking and distributed systems basics
- Basic observability and logging

### Deliverables
- Build a CRUD backend project
- Build a frontend/backend app integration
- Document system design choices
- Learn code review behavior

## Phase 5: Choose a specialization path (6-18 months)

### Choose one primary direction

#### A. Full-stack / backend / frontend
- HTML/CSS/JS/TypeScript
- React / Next.js / Vue / Angular
- Node / Django / FastAPI / Spring / Go
- Database design and APIs
- Deployment and cloud basics

#### B. AI / ML / Data Science
- Python for data
- statistics and probability
- linear algebra
- classical ML
- PyTorch / TensorFlow
- deep learning
- model evaluation and deployment
- MLOps basics

#### C. Embedded / Hardware / Computer engineering
- electronics basics
- C and microcontrollers
- GPIO, ADC, PWM, I2C, SPI, UART
- interrupts, timers, RTOS
- Verilog and FPGA basics
- hardware debugging and firmware bring-up

#### D. Cybersecurity / networking
- OS and network security
- cryptography
- web application security
- pentesting basics
- firewall, IDS, logging, monitoring
- secure coding

#### E. Robotics / automation / mechatronics
- electronics fundamentals
- sensing and actuation
- control theory
- ROS/ROS2
- kinematics and planning
- hardware integration

#### F. IT / systems / cloud / devops
- Linux and shell
- cloud fundamentals
- Docker and Kubernetes
- infrastructure as code
- CI/CD
- monitoring and reliability

#### G. Data engineering / fintech / telecom
- data pipelines
- ETL/ELT
- stream processing
- financial analysis and time series
- telecom and network concepts

## Phase 6: Production engineering depth (9-24 months)

### Goals
- Build production-ready systems
- Learn how large software systems are run in real life
- Learn reliability, scaling, monitoring, and ops

### Topic map
- CI/CD
- Docker and container orchestration
- Cloud architecture
- IAM and security
- Logging and tracing
- System health metrics
- Incident response basics
- Load balancing and scaling
- Caching and message brokers
- Reliability and observability

### Deliverables
- Deploy at least 2 projects publicly
- Build one production-like system
- Use logs, metrics, and monitoring
- Learn how deployment and failure handling work

## Phase 7: Portfolio and professional maturity (12-30+ months)

### Goals
- Convert learning into proof
- Demonstrate capability to employers or collaborators
- Build technical credibility

### Portfolio expectations
- 2-4 polished GitHub projects
- clear README files
- architecture explanation
- tests and documentation
- real-world problem solving
- deployment or demo
- open-source contribution when possible

### Practical maturity areas
- technical communication
- writing good documentation
- explaining trade-offs
- reviewing code
- debugging complex systems
- working in teams
- handling ambiguity and changing requirements

## Domain relationship map

All major domains in this repository are connected:

- Linux + OS + security + cloud + networking
- Programming + software engineering + backend + frontend + full-stack
- Electronics + microelectronics + embedded + robotics + automation
- AI + data science + data engineering + NLP + cognitive science
- IT + information systems + cloud + devops + operations
- Fintech + data + statistics + software + automation + analytics
- Telecom + networking + security + cloud + software-defined systems

No domain is truly isolated.

## Recommended weekly rhythm

- 4 days of concept learning
- 2 days of coding/building
- 1 day of review and notes
- 1 day of deep dive or project cleanup

## The strongest route to competence

If your goal is practical competence and not just curiosity:

1. Become strong in basics
2. Pick one main technical direction
3. Build real projects in that direction
4. Learn adjacent domains that support it
5. Repeat until your projects become professional-grade

## Final target

The final target is not just knowing many topics. The final target is:

- you can reason about systems
- you can build working software/hardware systems
- you can debug real issues
- you can explain architecture and trade-offs
- you can ship and maintain projects
- you can continue learning independently

This is the real meaning of being “professional.”

---

At this point, you are no longer a beginner exploring random tech. You are building a real engineering foundation.
