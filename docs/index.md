## Recommended learning flow

1. Start with the main README and master roadmap.
2. Complete the foundation and programming phases.
3. Build comfort with Linux, systems, and software engineering.
4. Move into AI and data work as the primary technical track.
5. Add supporting domains like security, embedded systems, and cloud operations.
6. Use the project ladder to validate skill with real work.

## How to use this repo

- Read the main roadmap first.
- Follow the sequence in order.
- Use the progress checklist to track proof of learning.
- Build one project per phase, not just notes and theory.
- Revisit the roadmap after each milestone.

This repository is meant to support long-term technical growth, not a one-time reading list.
