# Roadmap 90 Hari: Dari Fondasi ke AI Systems Builder

Dokumen ini adalah rencana aksi terperinci untuk 90 hari ke depan. Tujuannya bukan hanya belajar banyak topik, tapi membangun fondasi yang kuat lalu menanamkan kemampuan nyata.

## Prinsip utama

- Fokus pada urutan: fondasi -> CS core -> Python -> systems -> AI -> produk
- Setiap topik harus dijalani dengan praktik, bukan hanya membaca
- Proyek kecil harus dibangun sambil belajar
- Setelah satu fase selesai, lanjut ke fase berikutnya, bukan loncat-loncat
- Beban belajar harus konsisten, bukan sporadis

## Fase 1 (Hari 1-30): Fondasi berpikir dan membangun dasar teknis

### Tujuan
- membangun kebiasaan belajar yang disiplin
- menguatkan logika, pemahaman, serta cara berpikir ilmiah
- memulai Python dan terminal dengan benar

### Topik
- meta-learning, spaced repetition, Feynman technique
- first-principles thinking
- logika dasar dan berpikir ilmiah
- matematika dasar: angka, fungsi, aljabar sederhana
- probabilitas dasar
- statistik dasar
- terminal Linux
- Git dan GitHub
- Python dasar

### Output
- bisa menggunakan terminal dengan percaya diri
- bisa menulis program kecil dengan Python
- bisa menjelaskan konsep dengan bahasa sederhana
- punya catatan belajar yang rapi

### Proyek mini
- script CLI sederhana untuk tugas harian
- kalkulator atau analisis numerik dasar
- mini tool untuk data sederhana

## Fase 2 (Hari 31-60): CS Core dan sistem komputasi

### Tujuan
- memahami cara komputer bekerja secara mendasar
- membangun kemampuan problem solving
- menguasai struktur data dan algoritma dasar

### Topik
- struktur data: list, set, map, stack, queue, tree, graph
- algoritma pencarian dan pengurutan
- kompleksitas waktu dan ruang
- SQL dasar
- operating system fundamentals
- networking dasar
- Linux filesystem dan permissions
- debugging dan testing dasar

### Output
- memahami struktur data dan algoritma dengan benar
- bisa menulis solusi sederhana untuk masalah teknis
- bisa bekerja di lingkungan Linux dengan nyaman
- bisa memahami sistem dasar: proses, memori, I/O, jaringan

### Proyek mini
- CLI task manager
- file organizer automation
- mini data pipeline sederhana
- simple web API dengan Python

## Fase 3 (Hari 61-90): AI & produk nyata

### Tujuan
- masuk ke AI systems dari dasar yang benar
- membangun model, mengevaluasi, dan mengintegrasikan ke produk

### Topik
- NumPy dan Pandas
- analisis data dan visualisasi
- regression dan classification
- linear algebra untuk ML
- model evaluation
- overfitting dan generalization
- neural network dasar
- deep learning dasar
- NLP dasar
- LLM dan RAG dasar
- deployment model sederhana
- MLOps dasar

### Output
- bisa membangun model dari awal hingga evaluasi
- bisa menjelaskan trade-off model
- bisa membuat produk AI sederhana
- bisa mempublikasikan hasil proyek secara dokumentasi dan portofolio

### Proyek capstone
- chatbot atau document Q&A app
- AI summary or recommendation tool
- forecasting or classification app
- AI app with backend and deployment

## 90-day milestone checklist

### Milestone 1: Habits + foundation
- [ ] daily study habit formed
- [ ] terminal usage comfortable
- [ ] Git and GitHub used consistently
- [ ] Python basics completed

### Milestone 2: CS core mastery
- [ ] DS&A studied and practiced
- [ ] SQL basics complete
- [ ] Linux fundamentals complete
- [ ] debugging and testing practiced

### Milestone 3: AI pipeline readiness
- [ ] data processing complete
- [ ] classical ML basics complete
- [ ] model evaluation understood
- [ ] first simple model trained and validated

### Milestone 4: real product delivery
- [ ] AI project built end-to-end
- [ ] documentation ready
- [ ] deployment or demo working
- [ ] portfolio item published

## Recommended learning rhythm

- 2-3 jam belajar fokus setiap hari
- 1 jam latihan coding atau eksperimen
- 1 jam review dan note summary
- 1 proyek kecil setiap 2-3 minggu
- 1 review bulanan untuk melihat kemajuan

## Key rule

Do not learn only theory. Every major topic must end with at least one of these:
- code implementation
- project snippet
- diagram or explanation
- validation experiment
- portfolio artifact

Only then can it be considered truly learned.
