# Career paths and specialization map

This file gives a structured map of how to turn broad technical learning into clear career specialization.

## 1. Full-stack engineer path

### Core order
1. Foundations
2. Programming
3. Linux and Git
4. HTML/CSS/JavaScript
5. TypeScript
6. Frontend frameworks (React/Next.js)
7. Backend fundamentals
8. SQL and databases
9. REST APIs and auth
10. Testing and quality
11. Deployment and cloud basics
12. Security and observability
13. Production systems and scaling

### Typical portfolio projects
- Personal portfolio website
- Todo SaaS with auth and DB
- E-commerce backend + dashboard
- Multiservice app with CI/CD

## How to choose a path

Choose based on what you want to build:
- Build software systems -> software engineering / backend / frontend
- Build hardware systems -> embedded / CE / microelectronics
- Build intelligent systems -> AI/ML / NLP / data
- Build secure systems -> cybersecurity / networking
- Build autonomous devices -> robotics / automation
- Build infrastructure -> cloud / devops / data engineering

## Final advice

Do not try to learn everything at once. The goal is deliberate specialization after strong foundations. The most effective approach is:
- learn the foundations deeply
- choose one primary track
- gain practical project experience
- learn adjacent systems that support the track
- keep increasing depth in one direction

This is how a broad technical learner becomes a real engineer.
