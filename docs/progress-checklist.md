## Review routine

Use this rhythm:

- weekly: review what you learned
- biweekly: assess project momentum
- monthly: update checklist and priorities
- quarterly: choose next deepening domain

A topic is complete when you can:

1. explain it simply
2. apply it in code or practice
3. debug or improve it
4. connect it to a larger system
