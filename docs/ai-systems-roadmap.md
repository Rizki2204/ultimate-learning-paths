# AI Systems Roadmap

This roadmap is the AI-first specialization track inside the broader learning system. It is designed for a learner who wants to build useful intelligent systems rather than only consume theory.

## Learning objective

The goal is to become capable of creating AI systems that can:

- process real data
- train and validate models
- deploy working inference pipelines
- integrate with software systems
- operate in production responsibly

## Sequence

### 1. Python and data foundations
- Python fundamentals
- NumPy and Pandas
- data cleaning and feature extraction
- visualization
- Jupyter workflow

### 2. Math for AI
- statistics
- probability
- linear algebra
- calculus fundamentals
- optimization basics

### 3. Classical ML
- supervised learning
- regression and classification
- feature engineering
- evaluation metrics
- validation and overfitting
- tree-based models
- clustering and unsupervised methods

### 4. Deep learning
- artificial neural networks
- backpropagation
- optimization
- CNNs
- RNNs and sequence models
- transformers
- transfer learning

### 5. NLP and language systems
- tokenization
- embeddings
- text pipelines
- transformer basics
- fine-tuning and evaluation
- LLM tool use
- RAG and retrieval-based systems

### 6. MLOps and system integration
- experiment tracking
- model registry
- deployment architecture
- inference APIs
- monitoring
- drift detection
- CI/CD for ML systems

### 7. Real productization
- AI app design
- backend integration
- user experience and UX for AI
- security and privacy
- performance and scaling
- documentation and testing

## Recommended capstone tracks

### Track A — AI app builder
Build a real AI-assisted product using Python and a web framework.

### Track B — Data-to-model pipeline
Create an end-to-end pipeline from dataset to trained model to deployed service.

### Track C — LLM + retrieval system
Build a retrieval-augmented assistant using real documents.

### Track D — Vision or NLP product
Develop a classifier, summarizer, or chatbot with production-like deployment.

## Minimum proof of competence

To be considered viable in this track, a learner should be able to:

- clean and analyze real data
- train a model with validation and metrics
- explain the model choices
- deploy or serve the model
- integrate it into an application
- document trade-offs and limitations

This is the real AI systems path.
