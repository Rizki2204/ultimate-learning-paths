# Roadmap per karier (final): 0–24 bulan — target karier dan rencana belajar

Panduan ringkas, tersusun, dan dapat langsung dijadikan checklist per target karier. Untuk tiap jalur: tujuan 0–6 bulan (landasan), 6–12 bulan (proyek & penguatan), 12–24 bulan (produksi & spesialisasi).

1) Full-stack Engineer
- 0–6 bulan
  - HTML/CSS/JavaScript dasar, responsive layout
  - Git, terminal, Node.js, paket manager
  - TypeScript dasar
  - Proyek: personal portfolio + simple CRUD app
  - Checklist: deploy portfolio, testing dasar, GitHub repo rapi
- 6–12 bulan
  - Framework frontend (React + Next.js) dan state management
  - Backend ringan (Express / FastAPI / Django / Go) + REST API
  - Database relasional (Postgres) dan ORM dasar
  - CI/CD sederhana, deploy ke VPS / Cloud (Heroku / Vercel / Render)
  - Proyek: Todo SaaS lengkap (auth, DB, deploy)
- 12–24 bulan
  - Microservices dasar, caching, observability
  - Security basics, scaling patterns
  - System design kecil, testing end-to-end
  - Proyek: e-commerce / multiservice app, load-tested, production-ready

2) Backend Engineer
- 0–6 bulan
  - Data structures & algorithms dasar, Linux shell
  - HTTP, REST principles, SQL basics
  - One backend language (Go / Java / Python / Node)
  - Proyek: authenticated API
- 6–12 bulan
  - Databases (Postgres, replication), caching (Redis)
  - Background jobs, message queues (RabbitMQ / Kafka basics)
  - Observability: logs, metrics, tracing basics
  - Proyek: event-driven microservice demo
- 12–24 bulan
  - Distributed systems concepts, CAP, consistency models
  - System design at scale, deployment automation
  - Proyek: scalable service with CI/CD and infra-as-code

3) Frontend Engineer
- 0–6 bulan
  - JavaScript, TypeScript, DOM, CSS architecture
  - Build tools (Vite, bundlers), npm scripts, accessibility basics
  - Proyek: component-based portfolio
- 6–12 bulan
  - React/Next.js, SSR, routing, advanced state patterns
  - Performance optimization, testing (Jest, Playwright)
  - Proyek: interactive dashboard with tests
- 12–24 bulan
  - Design systems, component libraries, infra for frontend (CDN, edge)
  - Accessibility and internationalization at scale
  - Proyek: production UI library + app using it

4) Embedded / Computer Engineering
- 0–6 bulan
  - C programming, basic electronics (Ohm, circuits), breadboard projects
  - Microcontroller intro (Arduino / ESP32), toolchains
  - Proyek: blinking, sensors readout, serial logging
- 6–12 bulan
  - RTOS basics, hardware debugging (logic analyzer, oscilloscope basics)
  - Peripheral protocols (I2C, SPI, UART), PCB prototyping basics
  - Proyek: sensor + actuator controller with serial or network interface
- 12–24 bulan
  - Low-power design, bootloaders, hardware bring-up, certification basics
  - Proyek: embedded product prototype with firmware update path

5) AI / ML / Data Science / NLP
- 0–6 bulan
  - Python, linear algebra basics, probability, data wrangling (pandas)
  - ML basics: supervised learning, evaluation metrics
  - Proyek: regression/classification notebook and dataset
- 6–12 bulan
  - Deep learning basics (PyTorch/TensorFlow), model training, fine-tuning
  - MLOps intro: experiment tracking, reproducible pipelines
  - Proyek: deployable model with simple API and dataset pipeline
- 12–24 bulan
  - NLP pipelines, retrieval-augmented generation, production deployment
  - Model optimization, monitoring, data labeling pipelines
  - Proyek: end-to-end ML system (data ingestion -> model -> serving -> monitoring)

6) Cybersecurity / Networking / Telecom
- 0–6 bulan
  - Networking fundamentals (TCP/IP, routing, switching), Linux security basics
  - Common tools: nmap, tcpdump, Wireshark basics
  - Proyek: small network mapping and basic hardening checklist
- 6–12 bulan
  - Web app security (OWASP Top 10), incident response basics
  - Network services hardening, VPNs, PKI basics
  - Proyek: hardened web app + monitoring & alerting demo
- 12–24 bulan
  - Offensive/defensive tradeoffs, forensics basics, secure architecture
  - Proyek: simulated incident response and hardening report

7) Robotics / Mechatronics / Automation
- 0–6 bulan
  - Electronics basics, motor control fundamentals, ROS intro (ROS2 basics)
  - Sensors and actuators, PID control concept
  - Proyek: basic robot that moves and senses environment (simulation or hardware)
- 6–12 bulan
  - Perception basics (CV), control loops, state estimation
  - Integration: ROS nodes, middleware, simulation (Gazebo / Webots)
  - Proyek: mapping or navigation demo in sim/hardware
- 12–24 bulan
  - Real-time constraints, embedded control, perception optimization
  - Proyek: integrated robot that performs reliable real-world tasks

8) Cloud / DevOps / Platform
- 0–6 bulan
  - Linux, Docker, basic cloud concepts, Git workflows
  - Proyek: containerize a simple app and deploy to a cloud service
- 6–12 bulan
  - Kubernetes basics, Terraform, CI/CD pipelines, monitoring (Prometheus/Grafana)
  - Proyek: deploy multi-service app on k8s with CI/CD and observability
- 12–24 bulan
  - Platform design, autoscaling, SRE practices, cost optimization
  - Proyek: internal platform with infra-as-code and multi-environment promotion

9) Data Engineering
- 0–6 bulan
  - SQL, ETL basics, Python for data pipelines
  - Proyek: small ETL job that ingests CSV -> transforms -> loads to Postgres
- 6–12 bulan
  - Data warehouses, columnar stores, streaming basics (Kafka), orchestration (Airflow)
  - Proyek: scheduled pipeline that processes events and stores analytics
- 12–24 bulan
  - Data governance, partitioning, performance tuning at scale
  - Proyek: end-to-end data platform for analytics

---

Cara pakai: pilih satu jalur, ikuti checklist 0–6 bulan sampai selesai, lalu lanjut ke 6–12 dan 12–24. Simpan hasil proyek di portofolio dengan dokumentasi, link ke repo, demo, dan short write-up.
