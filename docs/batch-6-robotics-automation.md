# Batch 6 deep dive: Robotics, mechatronics, and automation

This batch brings together electronics, control, perception, software, and physical integration.

## Why this matters

Robotics connects:
- hardware and software
- sensors and actuators
- embedded control and real-time systems
- motion planning and autonomy
- simulation and testing
- physical constraints and safety

It is one of the most interdisciplinary technical domains.

---

## Learning flow

### Phase A: Control and motion basics (Weeks 1-8)

#### Topics
- mathematics for control
- linear algebra basics
- kinematics and dynamics basics
- sensors and actuators
- motors and drivers
- PWM and motor control
- encoders and feedback
- PID control basics
- open-loop vs closed-loop control

#### Tools
- C/C++ basics
- microcontrollers
- motor driver modules
- sensors

#### Projects
- line follower robot
- DC motor control experiment
- simple servo with feedback

#### Milestones
- [ ] Understand motor control and feedback
- [ ] Explain open vs closed loop control

---

### Phase B: Embedded robotics systems (Weeks 8-16)

#### Topics
- microcontroller and sensor integration
- GPIO and serial bus interfaces
- IMU and range sensors
- interrupts and timing
- power and safety basics
- real-time loops
- hardware debugging

#### Projects
- obstacle avoiding robot
- sensor-based movement system
- robot controller prototype

#### Milestones
- [ ] Design a basic robot controller
- [ ] Integrate sensors and motor driver logic

---

### Phase C: ROS and robot software (Weeks 12-20)

#### Topics
- ROS architecture basics
- nodes, topics, services, actions
- coordinate frames and transforms
- robot state and simulation
- navigation basics
- perception pipelines
- planning basics
- SLAM concepts
- ROS2 concepts

#### Tools and repos
- ros/ros: https://github.com/ros/ros
- ros2/ros2: https://github.com/ros2/ros2
- moveit/moveit: https://github.com/ros-planning/moveit
- PX4/PX4-Autopilot: https://github.com/PX4/PX4-Autopilot

#### Projects
- robot simulation with ROS
- autonomous navigation prototype
- sensor processing pipeline

#### Milestones
- [ ] Understand ROS architecture
- [ ] Build a robot system with nodes and messages

---

### Phase D: Perception and autonomy (Weeks 18-28)

#### Topics
- computer vision for robotics
- object detection and tracking
- mapping basics
- localization
- SLAM concepts
- path planning
- collision avoidance
- decision making under uncertainty

#### Tools
- OpenCV
- ROS perception packages
- camera integration

#### Projects
- robot vision pipeline
- object following robot
- mapping and navigation demo

---

### Phase E: Mechatronics and physical integration (Weeks 20-32)

#### Topics
- mechanical design basics
- servo and actuator selection
- power supply design
- system integration and constraints
- safety and reliability
- design trade-offs across hardware/software

#### Projects
- mobile robotics platform
- robot with sensors and controllers
- autonomous mobile prototype

#### Milestones
- [ ] Build a complete robot integration project
- [ ] Understand hardware/system trade-offs
