# Roadmap by career path

This file is meant to guide you based on the type of job or capability you want to build.

## 1) Backend engineer

### Learn in this order
- Python or JavaScript/TypeScript
- Linux + shell + Git
- SQL and database design
- HTTP and API design
- REST and auth
- backend framework
- testing and code quality
- microservice basics
- caching, queues, message brokers
- deployment and cloud basics
- monitoring and observability

### Typical stack
- Node.js / Express / NestJS
- Python / FastAPI / Django
- Java / Spring Boot
- PostgreSQL, Redis, Kafka

### Project ideas
- auth service
- billing service
- inventory backend
- task scheduling backend
- analytics API

### Project ideas

## Final rule

Choose one primary path, build actual projects in it, learn the adjacent disciplines that support it, and do not spread too thin.

This is the real formula for becoming solidly capable.
