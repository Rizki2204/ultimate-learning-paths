# Projects and Capstone Track

This directory is the practical execution layer for the roadmap. The goal is to turn learning into evidence, product thinking, and technical proof.

## Project ladder

### Level 1 — Mini projects
- Python CLI tool
- data analysis notebook
- small web app
- script automation tool
- simple sensor or hardware prototype

### Level 2 — Directed projects
- API with authentication
- model evaluation workflow
- secure web app
- embedded sensor project
- robotics or control demo

### Level 3 — Portfolio projects
- AI product with deployment
- secure service with testing
- robotics prototype with control loop
- end-to-end data pipeline
- full-stack app with real user flow

### Level 4 — Capstone
The capstone should combine at least two major skill layers, for example:

- AI + backend + deployment
- cybersecurity + app security + testing
- embedded + control + robotics
- data + ML + visibility + productization

## Suggested capstone themes

### AI systems capstone
- document Q&A assistant
- ML-driven recommender or prediction app
- RAG-based chatbot with evaluation
- production model API with monitoring

### Security capstone
- secure API with auth and threat model
- vulnerability assessment and remediation project
- secure monitoring and logging app

### Embedded / robotics capstone
- autonomous robot or sensor network
- embedded monitoring system
- control loop with hardware integration

### General systems capstone
- end-to-end product with backend, frontend, deployment, and monitoring

## Rules for a good project

A project is good if it has:

- a real problem
- clear technical architecture
- meaningful constraints
- validation and testing
- documentation
- measurable outcome

## Recommended progress model

For every project, complete:

1. define the goal
2. specify the architecture
3. implement core functionality
4. test the system
5. document assumptions and trade-offs
6. present the result clearly

This is how learning becomes capability.
