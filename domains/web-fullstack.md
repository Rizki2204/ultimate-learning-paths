# Embedded Systems

Embedded systems combine electronics, firmware, low-level programming, and practical integration with hardware.

## Core goals
- Learn microcontrollers and firmware
- Understand hardware-software interaction
- Interface sensors, actuators, communication buses
- Develop reliable real-world systems

## Learning sequence

### 1. Electronics basics
- voltage, current, resistance
- Ohm’s law
- power
- breadboards and circuits
- transistors and MOSFETs
- diodes
- regulators
- schematics

### 2. Digital logic and architecture
- logic gates
- binary, bit-level thinking
- memory and buses
- interrupts and timers
- ADC, DAC
- GPIO
- serial protocols

### 3. Microcontrollers
- Arduino
- ESP32
- STM32
- AVR/PIC
- bare-metal firmware
- C programming for microcontrollers

### 4. Communication protocols
- UART
- SPI
- I2C
- CAN
- Modbus
- MQTT
- BLE
- Wi-Fi

### 5. Real-time systems
- timers
- interrupts
- watchdogs
- debounce
- scheduling
- RTOS basics

### 6. Debugging and validation
- multimeter
- oscilloscope basics
- logic analyzer
- JTAG
- SWD
- serial monitoring

## Essential tools
- Arduino IDE

- VS Code
- GCC/clang
- OpenOCD
- gdb
- multimeter
- oscilloscope

- [ ] Understand circuit basics
