# Computational Linguistics and NLP

This domain studies language as a computational object and applies models to text, speech, and language processing systems.

## Core goals
- understand language structure and processing techniques
- build NLP systems and models
- connect language understanding to AI systems

## Topics
- phonology and phonetics
- morphology
- syntax
- semantics
- pragmatics
- tokenization
- parsing
- embeddings
- language modeling
- machine translation
- sentiment analysis
- summarization
- question answering
- classification
- speech recognition basics
- speech synthesis basics

## Essential ecosystem
- NLTK: https://github.com/nltk/nltk
- spaCy: https://github.com/explosion/spaCy
- Stanza: https://github.com/stanfordnlp/stanza
- Hugging Face Transformers: https://github.com/huggingface/transformers
- OpenAI ecosystem and open models

## Learning path
1. language basics and linguistics fundamentals
2. tokenization and preprocessing
3. classical NLP feature methods
4. embeddings and language models
5. transformers and LLMs
6. practical application pipelines
7. evaluation and deployment

## Project ideas
- sentiment classifier

- text generation demo
- chat assistant with retrieval
- multilingual text analysis tool
