# Cybersecurity / Hacking / Networking

Cybersecurity and networking are essential for trusted systems, secure architecture, cloud systems, IT operations, and engineering reliability.

## Core learning sequence

### 1. Networking basics
- OSI model
- TCP/IP
- HTTP, HTTPS
- DNS, DHCP, NAT
- routing and switching
- subnets
- IPv4/IPv6
- VLANs
- Wi-Fi basics

### 2. Security fundamentals
- CIA triad
- authentication vs authorization
- confidentiality
- integrity
- availability
- threat modeling
- risk analysis
- identity and access control

### 3. Application and web security
- OWASP Top 10
- SQL injection
- XSS
- CSRF
- SSRF
- deserialization vulnerabilities
- secure session handling
- secure defaults

### 4. Cryptography
- symmetric/asymmetric encryption
- hash functions
- signatures
- PKI/X.509
- TLS
- key exchange
- password hashing

### 5. Defensive security
- firewall basics
- intrusion detection
- IDS/IPS
- SIEM basics
- logging and monitoring
- incident response
- vulnerability management
- patching
- secure coding

### 6. Offensive security basics
- recon and enumeration
- scanning
- exploitation basics
- privilege escalation
- web exploitation
- malware basics
- reverse engineering basics
