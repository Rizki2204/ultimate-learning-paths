# Foundations

This domain is the base layer of the entire learning architecture. It is what allows a learner to think clearly, reason correctly, and learn efficiently across all technical fields.

## Why this domain matters

Without strong foundations, a learner will often feel confused, forget quickly, and jump between topics without real understanding. Foundations create the mental model needed for:

- mathematics
- programming
- systems thinking
- AI and ML
- hardware and robotics
- security and reliability

## Core goals

- learn how to learn efficiently
- build scientific and analytical thinking
- improve memory retention and understanding
- learn problem solving from first principles
- establish a durable study system

## Learning sequence

### 1. Learning methods and cognition
- meta-learning
- spaced repetition
- active recall
- retrieval practice
- Feynman technique
- memory systems and retention strategies
- study planning and consistency

### 2. First-principles thinking
- reduce problems to fundamentals
- understand assumptions
- break complex systems into meaningful parts
- avoid memorization without understanding

### 3. Systems thinking
- interconnected causes and effects
- feedback loops
- delays and nonlinear behavior
- emergence and complexity
- trade-offs in real systems

### 4. Scientific reasoning and epistemology
- observation vs inference
- hypotheses and testing
- skepticism and evidence
- validation and falsifiability
- uncertainty and probabilistic thinking

### 5. Formal logic
- propositional logic
- predicate logic
- deduction and induction
- contradiction and refutation
- proof structures

### 6. Mathematical foundations
- arithmetic and number sense
- algebra
- functions and transformations
- basic combinatorics
- probability basics
- statistics basics
- linear algebra basics
- discrete mathematics basics

## Core concepts checklist

- [ ] Use an effective study workflow
- [ ] Practice active recall and spaced repetition
- [ ] Explain a topic in plain English without notes
- [ ] Break complex problems into smaller parts
- [ ] Use first-principles reasoning on technical problems
- [ ] Understand the difference between memorization and understanding
- [ ] Use logic to evaluate claims and explanations
- [ ] Learn with evidence and structured review

## Practical study systems

- maintain a study journal
- write one-paragraph explanations for each new concept
- create quick revision cards
- review notes after 1 day, 3 days, and 7 days
- ensure each topic is connected to an application or project

## Project and proof ideas

- build a personal study tracker
- write concept explanations for major domains
- create a knowledge map of interrelated topics
- solve simple logic and reasoning exercises
- summarize mathematical concepts in plain language
