# Web Development / Frontend / Backend / Full-stack

Web development is one of the best practical routes into production engineering because it combines UI, UX, APIs, data, system design, security, DevOps, and deployment.

## Learning sequence

### 1. Frontend fundamentals
- HTML
- CSS
- Responsive design
- Flexbox and Grid
- JavaScript fundamentals
- DOM and browser APIs
- Event handling
- Forms and validation

### 2. Modern frontend development
- TypeScript
- React / Next.js / Vue / Angular basics
- Component design
- State management
- Routing
- Async data loading
- Error handling
- Performance optimization
- Accessibility

### 3. Backend foundations
- HTTP protocol
- REST API design
- Authentication and sessions
- JWT, OAuth2, OpenID Connect
- Database usage in backend
- Caching
- Validation
- API testing

### 4. Full-stack integration
- API integration
- Deployment and hosting
- CI/CD for web apps
- Authentication/authorization flows
- SSR/CSR/SSG concepts
- WebSockets
- File uploads
- Real-time app patterns
