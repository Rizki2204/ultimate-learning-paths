# AI / Machine Learning / Data Science

This domain is one of the most important and high-leverage technical tracks in the modern world. It combines math, statistics, software engineering, data handling, experimentation, and product thinking.

## Why this domain matters

AI is not just about models in notebooks. It is about understanding how data becomes signal, how signal becomes prediction, and how prediction becomes useful behavior in real systems.

This domain connects directly to:

- software engineering
- data infrastructure
- decision systems
- automation
- computer vision
- NLP and language systems
- MLOps and productization
- scientific and engineering reasoning

## Core goals

- understand how data drives learning
- master the math and statistics behind ML
- build and evaluate models carefully
- understand the difference between theory and production
- learn how AI systems become real products
- create portfolio-worthy AI projects

## Learning sequence

### 1. Data and Python foundations
- Python for data work
- NumPy
- Pandas
- data cleaning and transformation
- missing values and outliers
- feature engineering
- data visualization
- Jupyter workflow

### 2. Statistics and probability
- averages and distributions
- variance and standard deviation
- covariance and correlation
- probability distributions
- Bayes reasoning
- statistical inference
- confidence intervals
- bias and variance

### 3. Linear algebra and optimization
- vectors and matrices
- matrix operations
- eigendecomposition basics
- gradient descent
- loss functions
- optimization intuition
- regularization

### 4. Classical machine learning
- supervised learning
- regression
- classification
- decision trees
- random forests
- SVM
- k-NN
- Naive Bayes
- K-means clustering
- PCA
- model evaluation metrics
- cross-validation
- underfitting and overfitting

### 5. Deep learning
- neural network basics
- activation functions
- loss functions
- backpropagation
- optimization algorithms
- CNNs
- RNNs / LSTMs
- transformers
- attention
- embeddings
- transfer learning

### 6. NLP and multimodal learning
- tokenization
- text preprocessing
- embeddings and vector spaces
- transformers
- BERT / GPT intuition
- LLM basics
- prompt engineering
- RAG
- evaluation of LLM systems

### 7. Computer vision
- image representation
- convolution basics
- object detection basics
- classification and segmentation
- OpenCV workflows
- model pipelines for visual data

### 8. MLOps and deployment
- experiment tracking
- model versioning
- dataset versioning
- pipeline design
- inference serving
- API integration
- monitoring and drift detection
- model governance and evaluation

## Core concepts checklist

- [ ] Use Python for data work
