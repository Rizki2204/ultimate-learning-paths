# AI / Machine Learning / Deep Learning / Data Science

This domain is one of the most demanded and broadest in modern tech. It requires a solid base in Python, statistics, math, data handling, and production systems.

## Core learning order

### 1. Foundations
- Python for data science
- Numpy
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebook
- SQL for data analysis
- probability and statistics
- linear algebra
- calculus basics
- optimization basics

### 2. Classical ML
- supervised learning
- unsupervised learning
- dimensionality reduction
- clustering
- decision trees
- random forests
- SVM
- Naive Bayes
- feature engineering
- model evaluation
- bias-variance
- cross-validation

### 3. Deep learning
- neural networks basics
- backpropagation
- activation functions
- loss functions
- optimization
- CNNs
- RNNs
- LSTMs
- GRUs
- Transformers
- attention mechanism
- fine-tuning LLMs

### 4. NLP and Computer Vision
- tokenization
- embeddings
- language models
- BERT
- GPT and transformer models
- OCR
- image classification
- object detection
- segmentation
- generative models

### 5. Production ML
- MLOps
- experiment tracking
- versioning datasets and models
- model serving
- metrics monitoring
- pipelines
- deployment strategies
- inference optimization

## Recommended study path
- Start with Python + statistics + linear algebra
- Then use scikit-learn for classic ML projects
- Then move into deep learning with PyTorch
- Then learn transformers and LLMs
- Then learn deployment, pipelines, and MLOps
