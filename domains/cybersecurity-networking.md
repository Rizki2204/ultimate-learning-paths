# Cybersecurity and Networking

Cybersecurity is the discipline of protecting systems, data, software, users, and infrastructure from malicious or unintended harm. It is one of the most important supporting domains for modern engineering because every serious system eventually becomes a security problem.

## Why this domain matters

Security is not an isolated topic. It is a property of every system, including:

- operating systems
- applications
- APIs
- networks
- cloud infrastructure
- embedded devices
- AI systems
- robotics

Understanding security makes you a more capable builder, not just a “hacker.”

## Core goals

- understand the security model of real systems
- understand technical risks and attack surfaces
- learn secure coding and secure architecture principles
- understand networking and protocol threats
- become aware of detection, mitigation, and incident response basics
- develop a defensive mindset for engineering work

## Learning sequence

### 1. Networking and protocols
- OSI and TCP/IP
- IP addressing and subnetting
- ARP, DNS, DHCP, NAT
- HTTP, HTTPS, TLS
- routing and switching
- LAN/WAN fundamentals
- packet analysis basics

### 2. Security fundamentals
- CIA triad
- authentication vs authorization
- confidentiality, integrity, availability
- threat modeling
- risk analysis
- identity and access control
- secure defaults

### 3. Application and web security
- OWASP Top 10
- SQL injection
- XSS
- CSRF
- SSRF
- IDOR
- insecure deserialization
- session security
- secure API design

### 4. Cryptography basics
- symmetric vs asymmetric encryption
- hashing and integrity
- signatures and certificates
- PKI basics
- TLS basics
- password hashing
- key exchange concepts

### 5. System and infrastructure security
- Linux security basics
- file permissions and privilege boundaries
- firewall basics
- IDS/IPS basics
- SELinux/AppArmor basics
- patch management
- monitoring and logging basics
- container security basics

### 6. Offensive security basics
- recon and enumeration
- scanning
- web exploitation basics
- privilege escalation concepts
- malware basics
- reverse engineering basics
- exploit chains and mitigation thinking

### 7. Defense and incident response
- logging and alerting
- SIEM basics
- forensic basics
- vulnerability management
- incident handling basics
- secure development lifecycle

## Core concepts checklist

- [ ] Understand OSI and TCP/IP
- [ ] Understand HTTP, TLS, and packet flow
- [ ] Learn authentication and authorization design
- [ ] Learn web security weaknesses and mitigations
- [ ] Understand hashing, encryption, and PKI basics
- [ ] Learn attack surfaces and threat modeling
- [ ] Understand system hardening and logging
- [ ] Develop a secure coding mindset
