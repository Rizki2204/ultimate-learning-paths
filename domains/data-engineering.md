# Cloud / DevOps / Platform Engineering

Cloud and DevOps are where software delivery, automation, systems reliability, and infrastructure meet.

## Core goals
- understand infrastructure as code
- automate deployments and operations
- learn cloud basics and production workflows
- improve reliability and observability

## Learning path

### 1. Fundamentals
- Linux command line
- networking basics
- security basics
- shell scripting
- Git workflows
- virtualization and containers
- DNS, HTTP, TLS

### 2. Containers and orchestration
- Docker
- container images
- networking with containers
- Kubernetes basics
- Helm
- Pods, Deployments, Services
- Ingress
- ConfigMaps and Secrets
- stateful vs stateless workloads

### 3. Infrastructure as Code
- Terraform
- Ansible
- Pulumi basics
- configuration management
- environments and provisioning
- declarative infrastructure

### 4. CI/CD
- GitHub Actions
- Jenkins
- GitLab CI
- automated testing
- build pipelines
- release workflows
- deployment strategies

### 5. Cloud platforms
- AWS basics
- Azure basics
- GCP basics
- identity, networking, storage, compute, databases, IAM
- serverless basics

### 6. Observability and reliability
- logs
- metrics
- tracing
- Prometheus
- Grafana
- OpenTelemetry
- SRE basics
- incident response

## Project ideas
- Dockerized backend app
- multi-service deployment on local Kubernetes
- Terraform based infrastructure setup
- CI pipeline for a full-stack app
- metrics dashboard with Prometheus and Grafana
- deployment blue/green pipeline

## Milestone checklist
- [ ] Use Linux shell effectively
- [ ] Understand Docker basics
- [ ] Understand containers and images
- [ ] Run a simple local Kubernetes cluster
- [ ] Write IaC with Terraform or Ansible
- [ ] Build CI/CD pipeline
- [ ] Understand cloud resource basics
- [ ] Set up monitoring and logs
