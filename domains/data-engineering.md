# Data Engineering

Data engineering is the discipline of building systems that reliably move, transform, store, and make data usable for analytics, AI, software products, and operational decisions.

## Why this domain matters

AI, analytics, and modern software products are only as good as the data pipelines behind them. Data engineering is what turns raw sources into trustworthy information systems.

This domain connects closely to:

- software engineering
- AI / ML / Data Science
- databases
- cloud and infrastructure
- analytics
- business systems
- observability and operational reliability

## Core goals

- understand how data flows through systems
- build reliable pipelines for collection and transformation
- learn storage, warehousing, and modeling principles
- understand batch vs streaming patterns
- create data products that support analytics and AI
- connect engineering to operational and decision-making systems

## Learning sequence

### 1. Data fundamentals
- data types and schemas
- structured vs unstructured data
- batch vs streaming
- ETL and ELT
- data quality
- lineage and governance
- data contracts

### 2. Databases and storage
- SQL basics and advanced queries
- relational model
- indexing and partitions
- warehouse vs lake concepts
- dimensional modeling
- data modeling basics
- transactional vs analytical systems

### 3. Data pipelines
- ingestion patterns
- API-to-database pipelines
- file ingestion
- transformation logic
- orchestration
- scheduling and retries
- backfills and reprocessing

### 4. Streaming and event systems
- Kafka basics
- event-driven architecture
- message queues
- consumer/producer patterns
- buffering and replay
- stream processing fundamentals

### 5. Data platforms and operations
- Airflow basics
- orchestration
- monitoring and alerting
- pipeline testing
- data quality checks
- observability for data systems
- lakehouse architecture concepts

### 6. Analytics and AI support
- serving cleaned data to models and dashboards
- feature generation
- metric pipelines
- operational analytics
- BI and reporting pipelines

## Core concepts checklist

- [ ] Understand ETL and ELT pipelines
- [ ] Use SQL for transformation and analysis
- [ ] Understand warehouse and lake ideas
- [ ] Build a small batch pipeline
- [ ] Learn streaming fundamentals
- [ ] Understand data quality and lineage
- [ ] Connect data products to AI or analytics
- [ ] Monitor and troubleshoot pipeline failures
