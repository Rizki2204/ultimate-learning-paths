# Software Engineering

Software engineering is not only writing code. It is about building maintainable, testable, scalable, and dependable systems.

## Core goals
- Understand the software lifecycle
- Write maintainable code
- Design systems with trade-offs
- Use tests, reviews, CI/CD, and documentation
- Scale software safely

## Learning sequence

### 1. Code quality fundamentals
- clean code
- naming and readability
- modularity
- refactoring
- code review practices
- comments and documentation
- testing strategy

### 2. Architecture basics
- layered architecture
- monolith vs microservice
- modular design
- separation of concerns
- dependency management
- interfaces and contracts

### 3. Data and persistence
- SQL and object models
- repository patterns
- caching
- migrations
- data consistency

### 4. APIs and integration
- REST
- GraphQL
- gRPC
- WebSockets
- OAuth/OIDC
- rate limiting
- API documentation

### 5. Production engineering
- CI/CD
- testing
- observability
- monitoring
- logging
- tracing
- performance profiling
- reliability

### 6. Scaling and distributed systems
- load balancing
- caching
- partitioning
- replication
- backups
- fault tolerance
- eventual consistency
