# Telecommunication and Network Engineering

This domain focuses on data communication, network design, telecom infrastructure, and the systems that connect people, devices, and services.

## Core goals
- understand communication systems
- learn network design and protocol behavior
- understand telecom and wireless infrastructure
- build practical troubleshooting and analysis skills

## Topics

### Networking basics
- OSI model
- TCP/IP model
- IPv4 and IPv6
- subnetting
- routing
- switching
- DNS
- DHCP
- NAT
- QoS
- VLANs
- firewalls

### Wireless and telecom
- Wi-Fi basics
- Bluetooth
- cellular networking
- LTE
- 5G basics
- signal propagation
- antennas and spectrum basics
- network planning

### Infrastructure and operations
- WAN/LAN design
- monitoring and telemetry
- capacity planning
- traffic engineering
- packet analysis
- troubleshooting workflows

## Tools
- Wireshark: https://github.com/wireshark/wireshark
- Nmap: https://github.com/nmap/nmap
- Scapy: https://github.com/secdev/scapy
- Open vSwitch concepts
- gns3 / network emulators

## Project ideas
- small LAN lab
- packet analyzer for local traffic
- DNS troubleshooting lab
- QoS simulation
- simple route design and subnet mapping
- cellular network study project

## Milestone checklist
- [ ] Understand OSI and TCP/IP
- [ ] Configure and troubleshoot local networks
- [ ] Understand IP addressing and routing
- [ ] Use packet analysis tools
- [ ] Learn telecom and wireless basics
- [ ] Understand network design and monitoring
