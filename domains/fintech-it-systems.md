# Robotics / Mechatronics / Automation

This domain combines control systems, electronics, software, mathematics, and hardware design.

## Core learning areas
- kinematics and dynamics
- control systems
- robotics perception
- localization and mapping
- path planning
- robot programming
- embedded controllers
- sensor and actuator integration
- mechatronics design

## Learning path

### 1. Foundations
- math and linear algebra
- C/C++ basics
- Python basics
- electronics basics
- signal processing basics

### 2. Control and motion
- PID control
- state estimation
- open-loop and closed-loop control
- actuator control
- motor drivers
- encoders
- IMUs

### 3. Robot software
- ROS / ROS 2
- robot frames and transforms
- trajectory generation
- SLAM basics
- navigation
- planning
- simulation

### 4. Mechatronics integration
- sensors and actuators
- power systems
- mechanical design principles
- hardware/software co-design
- reliability and safety
