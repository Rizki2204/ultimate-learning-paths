# Resources and learning sources

This file is the curated, accessible learning resource library for the repository. Each topic includes direct links to the best publicly available sources so a learner can go from concept to practice without searching blindly.

## How to use this resource list

- Prioritize official documentation and canonical references first.
- Pair each concept with one practical project or coding exercise.
- Use this file as a direct-access index, not a passive reading list.
- For the fastest path, follow the sequence in the main README and master roadmap.

## Resource ranking priority

1. Official docs and canonical references
2. University lecture series and course notes
3. Reputable free courses and learning platforms
4. High-quality GitHub repos and tooling docs
5. Personal blogs only if they explain a concept clearly and accurately

## Final resource principle

The best learning workflow is:

1. Learn the concept from an official source.
2. Reinforce it with a tutorial or course.
3. Practice with a project.
4. Validate understanding by explaining the concept in your own words.
5. Repeat at a higher level of complexity.

This is how the repository’s roadmap becomes real capability.
